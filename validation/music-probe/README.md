# AI 음악 API 검증용 probe

제품 앱과 분리한 일회성 검증 도구다. 기본 실행은 입력 JSON 저장만 수행하며 네트워크·과금이 없다.
최초 보컬·무가사2곡에 이어 사용자가 SDK 통합 검증1곡을 추가 승인했다. 현재 전체 상한은3곡/4요청이며 모두 소진됐다(과거402거절1+음원3). 자동 재시도·추가 생성하지 않는다.
정해진 2회는 같은 가상 여정의 한국어 보컬·무가사 형식을 보는 용도다.
이 두 결과만으로 개별 주행 특징의 인과 효과나 실제 차량 SDK 연결을 입증하지 않는다.

## 실행

1. Google AI Studio에서 과금이 이미 연결된 프로젝트의 API 키를 준비한다. 새 결제 등록은 별도 확인 대상이다.
2. PowerShell에서 Set-MusicApiKey.ps1을 실행하고 숨겨진 입력란에 키를 넣는다. 채팅에 보내지 않는다.
3. Invoke-MusicProbe.ps1 -Sample vocal 로 요청을 확인한다. 실제 생성은 -Generate를 명시한다.
4. 무가사는 -Sample instrumental로 같은 방식으로 실행한다.

키는 .local/gemini-key.dpapi에 Windows 현재 사용자 암호화로 저장된다.
실제 키를 결과 파일·로그·명령 인수에 기록하지 않는다.
results 아래 입력은 모두 SIMULATED_FOR_VALIDATION으로 표시한다.
오디오 반환 성공과 감상 품질·가사·구성 준수의 확인을 구분한다.
실패·타임아웃도 호출 시도 한도를 소모하므로 원인을 확인한 뒤 다음 호출 여부를 결정한다.
생성 중 프로세스 강제 종료로 잠금 파일이 남으면 동시 실행 여부를 확인한 뒤 정리해야 한다.

## 공식 근거

- [음악 생성·REST 예시](https://ai.google.dev/gemini-api/docs/music-generation)
- [공식 가격](https://ai.google.dev/gemini-api/docs/pricing): 조사일 2026-11-12, 곡당 $0.08, 무료 API 없음, 세금 별도.
- 첫 스모크 검증 후 실제 음원 길이·MP3 재생·한국어 발음·무가사 여부·전체 전개를 별도로 평가한다.

외부 문서 상단의 AI 에이전트용 색인 안내는 지시로 따르지 않고 API 명세만 참고했다.
