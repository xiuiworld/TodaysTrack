# 접수 메일 초안

2026-11-15 제출 준비 대화에서 정리한 문안이다. 실제 대표자 이름·팀원 이메일·서명이 포함된 첨부파일은 사용자가 준비한다. 이메일 발송 또는 접수 완료 기록이 아니다.

공식 근거: [지원·제출 방법](https://appdevchallenge.auto-hmg.io/guide/submission), [FAQ](https://appdevchallenge.auto-hmg.io/faq).

받는 사람: `appdevchallenge@hyundai-partners.com`

참조(CC): 참가 팀원 전원

## 제목

```text
[차량용 앱 개발 공모전] 맘보코어_대표자명
```

## 본문

```text
안녕하세요.
현대자동차그룹 차량용 앱 개발 공모전에 참가하는 맘보코어 대표 [대표자명]입니다.

‘오늘의 트랙(Today’s Track)’의 접수양식(기획서) 및 개인정보 수집·이용 동의서를 첨부하여 제출합니다.

오늘의 트랙은 주행이 끝난 뒤 차량에 기록된 여정으로 AI 음악을 만들어, 함께 달린 시간을 한 곡으로 간직하는 Pleos Connect 앱입니다.

시연 영상과 개발 산출물은 아래 링크에서 확인하실 수 있습니다.

1. 시연 영상
https://youtu.be/bQ5uMmf7UIw

2. GitHub 저장소
https://github.com/xiuiworld/TodaysTrack

3. APK 및 소스 다운로드
https://github.com/xiuiworld/TodaysTrack/releases/tag/submission-v0.4.0

감사합니다.

```

사용자는 작성한 메일에서 최종 커밋 항목을 생략했다고 설명했다. 위 본문은 그 문안을 보존한 것이며, 공식 제출 안내는 메일에 저장소 주소와 최종 전체 커밋 번호를 적도록 요구한다. 커밋을 추가할 경우 발송 직전 원격 main의 값을 확인한다.

## 파일명

- 접수 PDF 추천: `맘보코어_오늘의트랙_접수양식_개인정보동의서.pdf`. 공식 지정 파일명이나 PDF 필수 요건이 아니다.
- 실제 공개 APK: `MamboCore_TodaysTrack_release.apk`. 이미 저장소와 Release에 사용한 영문 팀명·앱명 표기를 유지한다. 메일 초안 안내에서 제안했던 한글 APK명으로 다시 바꾸지 않는다.

현재 공개 산출물 경로와 제출 전 확인 항목은 [제출 체크리스트](submission-checklist.md)를 따른다. 개인정보·서명이 있는 접수양식은 이 저장소에 추가하지 않는다.
