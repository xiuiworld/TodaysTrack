## 새 기록 시작 장면용 합성 입력 도구

Pleos와 앱·localhost 서버는 열린 상태로 둔다. 수집 중인 기존 기록이 있으면 도구가 중지하므로 먼저 사용자가 마감한다. 이 도구는 제품 코드·DB를 직접 수정하지 않고 실제 SDK 입력만 공급한다. 영상을 녹화하거나 음악 API를 부르지 않으며 최대180초 내 끝난다.

‘합성 입력6/6 완료’ 뒤 앱의 ‘기록 마감’을 누른다. 약30초로 가속한 A-B-C-C-B-A/8km 합성 관측이며 실제 주행 시간·정차나 방문을 입증하지 않는다. 도구는 GPS test provider와 shell mock-location 설정을 실행 후 복원한다. 기록·곡·기존 작업 ID는 삭제하지 않는다.

유료 생성이 거절되거나 접수 여부가 불명확하면 새 기록을 만들어 반복 생성하지 않는다. 기존 작업 확인과 보관된 입력을 사용하고, 현재 비용 승인 범위를 넘어서는 호출은 하지 않는다. 앱의 실제 첫 클릭·재생 포커스 결과를 그대로 촬영하며 실패를 성공으로 편집하지 않는다.

## 준비 근거와 보존

`.local/filming`에 SDK 입력 로그·실행 전 서버 DB 백업·기존 행 대조·MediaSession PLAYING/PAUSED 근거가 있다. `.local/android-ui-device/collections`에는 실제 화면 XML/PNG와48개 호스트 검사·release 빌드/브라우저10개 검사 로그가 있다. 서버 요청에 따른 일회용 인증 nonce의 자연 만료는 기록·곡·고정 입력 삭제와 구분한다. 로직·서버 제품 코드와 MainActivity는 이번 UI 간격 수정에서 변경하지 않았다.
