# 오늘의 트랙 · 경쟁 서비스 및 선행 사례 조사

조사 기준일: 2026-11-12 · 목적: 내부 제품 방향·MVP 결정 · 실제 앱 체험: 미실시

관련 문서: [내부 상세 기획서](../product/product-plan.md) · [현대자동차그룹 제출용 기획서](../proposal.md)

## 1. 요약

**오늘의 트랙의 제품 차이는 주행이 끝난 뒤 전체 기록으로 AI가 완결된 곡을 만든다는 경험에 있다.** 주행 중 반응형 음악, 풍경 음악화, GPX 음악 재생은 인접 선행 사례이며 같은 서비스로 간주하지 않는다. 최초성 전체를 입증하는 조사는 아니지만, 각 사례의 입력·생성 시점·결과물을 구분하면 차별화할 방향은 분명해진다.

| 주요 발견 | 기획에 주는 의미 |
| --- | --- |
| 벤츠·포르쉐는 주행에 반응하는 음악을 공개했다 | 실시간 반응 자체를 새로움의 전부로 삼기 어렵다 |
| 현대자동차그룹 내 기아도 풍경을 음악으로 바꾸는 프로젝트를 공개했다 | ‘그룹에 없는 발상’이라고 소개하면 반박될 수 있다 |
| AudioDrive는 휴대폰으로 주행 반응형 음악을 제공한다고 설명한다 | 차량 전용 하드웨어가 필수라는 주장을 피해야 한다 |
| Geosonify는 GPX 경로를 음악으로 재생하고 지도와 맞추는 기능을 설명한다 | 주행 후 변환·지도 연동만으로도 최초성을 입증할 수 없다 |
| Polarsteps·Relive는 이동을 소장 가능한 여행 기록으로 바꾼다 | 실제 경쟁 상대에는 음악 앱뿐 아니라 기존 여행 기록도 포함된다 |
| Suno 등은 일반 음악 생성의 대안이다 | 설명 없이도 듣기 좋은 결과와 여정을 반영한 이유를 함께 보여줘야 한다 |

위 사실의 제품별 근거는 아래 비교표와 상세 검토에 연결했다. **현재 기획 방향:** 실제 차량 기록→전체 여정의 구성안→AI 곡 생성→감상·소장이다. 음악 품질·차량 데이터 기여·개인적인 의미를 각각 검증한다. 앨범·폰·설정은 이 경험을 지원한다. 이 보고서의 추천은 최신 인터뷰를 반영해 수정했으며 구현·고객 검증 결과는 아니다.

### 조사 방법과 해석 기준

- 공식 제조사 발표, 운영사 웹사이트, 개발자 문서, 개발자 제공 앱스토어 설명, 원 논문을 우선했다.
- `확인 사실`은 해당 출처에서 확인한 설명이다. 품질·효능을 독립 검증했다는 의미가 아니다.
- `해석`과 `추천`은 오늘의 트랙에 적용한 판단이며, 경쟁사가 인정한 평가가 아니다.
- `미확인`은 사용성, 한국 제공 여부, 실제 API 접근, 다운로드·결제 등의 실동작을 조사하지 못했음을 뜻한다.
- 발표·프로토타입·파일럿·웹 도구·판매 앱을 구분한다. 2021년 발표를 2026년 현재 양산 기능으로 바꿔 말하지 않는다.
- 공개 소개에 없는 기능은 ‘공개자료에서 확인하지 못함’으로만 기록한다. 기능 부재를 증명한 것으로 취급하지 않는다.
- 앱을 설치·구매하거나 계정을 연결하지 않았다. 레이턴시·음질·권리의 적합성을 직접 실험한 결과도 없다.

## 2. 주요 발견과 경쟁 비교

### 2.1 비교 범위

조사 질문은 “음악을 만드는 앱이 있는가”에 한정하지 않는다. 고객의 시간을 놓고 경쟁하는 대안과 같은 기술 발상을 가진 사례를 함께 본다.

| 구분 | 조사 대상 | 비교 이유 |
| --- | --- | --- |
| 차량·이동 반응형 음악 | MBUX SOUND DRIVE, Soundtrack My Life, AudioDrive, Endel Car Experience | 주행 상황과 음악을 연결한다 |
| 풍경·경로의 음악화 | Kia Soundscapes, Geosonify | 여정을 음악 재료로 쓰는 발상과 가깝다 |
| 차량 창작 도구 | Tesla TRAX | 사용자가 처음 참고한 테슬라의 차량 내 음악 창작 기능 |
| 이동 기념물 | Polarsteps, Relive, TrackList | 이동 기록을 보관·공유하는 고객 과업을 해결한다 |
| 일반 음악 생성·기술 | Suno, Eleven Music, Lyria RealTime, Magenta RealTime 2 | 더 쉬운 대안 및 구현 후보와 비교한다 |
| 연구 선행 | Drive-to-Music, SoundScape | 기술 발상·소리 기억이라는 주제의 선행 연구를 확인한다 |

### 2.3 중요 사례별 검토

#### A. Mercedes-Benz MBUX SOUND DRIVE

**확인 사실:** 2024-01-09 제조사 발표는 주행 신호를 음악적 표현으로 변환한다고 설명한다. 같은 해 중반부터 MBUX 2세대 적용 차량에 전개할 계획을 발표했다. [제조사 발표](https://media.mbusa.com/news/mercedes-amg-and-william-launch-immersive-mbux-sound-drive-experience-at-ces-2024)

**해석:** ‘차량을 악기로 만든다’는 메시지와 실시간 반응 시연은 이미 강한 비교 대상이다. 오늘의 트랙이 같은 표현을 핵심 차별점으로 쓰면 약하다.

**추천:** 운전 중 연주보다, 여행이 끝나도 남는 완성곡·앨범·회고의 가치를 먼저 보여준다. 상대 기능에 저장·내보내기가 없다고 단정하지 않는다. 실제 지원 차종·한국 판매·가격·현재 이용 가능성은 이번 조사에서 확정하지 않았다.

#### B. Porsche Soundtrack My Life

**확인 사실:** 2021년 공식 기사는 가속·속도·원심력에 따라 미리 작곡한 요소의 믹스를 바꾸는 방식을 설명한다. 당시에는 스마트폰 프로토타입이었고 PCM 내장 여부가 정해지지 않았다고 했다. [포르쉐 공식 기사](https://newsroom.porsche.com/en_US/2021/technology/porsche-digital-adaptive-sound-soundtrack-my-life-development-norman-friedenberger-boris-salchow-24848.html)

**해석:** 규칙 기반 조합은 AI의 대안으로 합리적이지만, 구현 방식 자체의 새로움을 주장할 근거는 아니다. 이 자료는 오래된 개발 소개이며 현재 출시 상태를 입증하지 않는다.

**추천:** 조합 엔진보다 여정에서 테마·구조를 결정하고 왜 그런 결과가 나왔는지 보여주는 경험에 집중한다.

#### C. AudioDrive

**확인 사실:** 개발자 제공 App Store 설명은 iPhone 센서로 주행에 따라 음악을 변화시키고, 앱 라이브러리·주행 모드·센서 감도 선택을 제공한다고 한다. 미국 스토어에는 Pro Monthly $9.99와 Lifetime $29.99 등 구매 항목이 표시된다. 같은 화면의 다른 Pro 항목은 기간이 불명확해 가격 비교에 쓰지 않았다. [App Store](https://apps.apple.com/us/app/audiodrive-drive-make-music/id6636472047)

**해석:** 차량 데이터 연동 없이도 유사한 음악적 재미를 제공하는 대안이다. 실제 동작 품질과 결제·한국 제공 여부는 체험하지 않았다.

**추천:** ‘차에서만 가능’이라는 주장 대신 실제 차량값의 기여·기록 흐름·차량 오디오 연동을 증명한다. 미국 표시 가격은 한국 결제 가격이나 오늘의 트랙 가격의 근거가 아니다.

#### D. Kia Soundscapes

**확인 사실:** 2025-06-05 현대자동차그룹 공식 소개는 시각장애인의 풍경 경험을 확장하는 예술 프로젝트로 설명한다. 카메라와 추가 센서·AI로 주변 자연을 분류하고 음악화하는 접근이다. [그룹 공식 소개](https://www.hyundaimotorgroup.com/en/story/kia-soundscapes-sound-of-movement), [기아 프로젝트 페이지](https://www.kia.com/eu/about-kia/inspiredbykia/soundscapes.html)

**해석:** 같은 그룹 심사에서 가장 주의할 인접 사례다. 다만 풍경 인식 장치를 쓴 프로젝트와 공개 Connect SDK 앱은 접근 가능한 입력부터 다르다. 이를 일반 차량의 기본 앱이나 공모전 허용 API 사례로 간주하면 안 된다.

**추천:** 접근성을 명분으로 억지 확장하거나 카메라 접근을 가정하지 않는다. 풍경의 번역과 여정의 음악 기념물을 구분해 설명한다.

#### E. Geosonify

**확인 사실:** 공개 화면에 GPX 입력과 실시간·압축 재생 제어가 있다. 공식 사이트의 검색 색인으로 읽힌 FAQ는 경로를 음악으로 재생하고 지도 마커를 동기화하며, 전체 이동을 짧은 길이로 압축하고 BPM에 맞출 수 있다고 설명한다. 주체는 Greg O'Beirne로 표기돼 있다. [공식 웹 도구·FAQ](https://geosonify.org/)

**조사 한계:** 직접 열린 페이지의 텍스트 추출에는 FAQ가 전부 나오지 않아 공식 URL의 검색 색인 설명도 함께 사용했다. GPX 업로드·실제 청취·음원 내보내기는 실행하지 않았다.

**해석·추천:** 오늘의 트랙의 가까운 선행 사례다. ‘완주 후 음악화’나 ‘경로와 동기화’만으로 차별화하지 말고, 음악의 완결성·차량값 기여·보관과 재감상의 경험을 비교 검증한다. Geosonify보다 음질이 좋다는 결론은 아직 낼 수 없다.

#### F. Tesla TRAX

**확인 사실:** 확인한 Model 3 영문 홍콩 매뉴얼은 TRAX를 정차 상태에서 악기·소리를 골라 음악을 만드는 기능으로 설명한다. 같은 문서는 기능이 시장·제조 시기·구성에 따라 달라질 수 있다고 알린다. [Tesla 공식 매뉴얼](https://www.tesla.com/ownersmanual/model3/en_hk/GUID-79A49D40-A028-435B-A7F6-8E48846AB9E9.html)

**해석:** 주행 데이터로 여정을 곡으로 만드는 직접 경쟁과는 다르지만, 차 안에서 창작하는 재미의 기준점이다. 이 매뉴얼만으로 ‘테슬라 전체에 여정 음악 기능이 없다’고 결론 내릴 수 없다.

**추천:** 작곡 UI를 차에 옮기기보다, 사용자가 작곡을 배우지 않아도 이동이 재료가 되는 진입 방식을 보여준다.

#### G. Endel Car Experience

**확인 사실:** 2021-07-19 보도자료는 Mercedes-Benz Group Research와의 파일럿을 설명한다. 주행·날씨·도로·개인 지표에 맞춘 적응형 사운드로 집중·이완을 돕겠다는 목표다. [Endel 공식 보도자료](https://static.endel.io/presskit/Endel-PressRelease-EndelCarExperience.pdf)

**해석:** 상황에 반응하는 소리라는 기술 영역은 겹치지만 주요 고객 목적은 다르다. 자료에 적힌 효과는 사업자의 주장으로 취급하며, 이 조사로 운전 안전 효과를 검증하지 않았다. PDF의 실제 발표일은 2021년으로, 검색의 최근 수집일과 혼동하지 않는다.

**추천:** 오늘의 트랙을 집중력 향상·스트레스 치료 서비스로 포장하지 않는다. 당시 파일럿이 현재 모든 벤츠 차량에 제공된다고 소개하지 않는다.

#### H. Polarsteps와 Relive

**확인 사실:** Polarsteps는 자동 여행 경로 기록과 사진·이야기, Travel Books·Plus를 설명한다. Relive는 경로·활동을 영상으로 만들고 음악 추가·고화질 등을 유료 기능으로 안내한다. [Polarsteps](https://www.polarsteps.com/travel-tracker), [Relive Plus](https://www.relive.com/plus?hl=en)

**해석:** 음악 생성이 없어도 여행을 간편하게 남기는 가치를 제공한다. 오늘의 트랙은 기존 기록 앱과 비교해 결과물의 의미와 재사용 동기가 있어야 한다.

**추천:** 로컬 앨범의 저장·재생을 기본 경험으로 완결한다. 공유를 성장 가설로 삼되, 실제 전달 경로를 검증하기 전 유입 효과를 숫자로 만들지 않는다.

#### I. TrackList

**확인 사실:** 운영자 소개는 Strava 경로와 음악 청취 이력을 연결해 곡별 색상 경로·앨범아트·세트리스트 포스터를 만든다고 설명한다. 개인 프로젝트로, 무료와 후원 경로가 안내돼 있다. [개발자 소개](https://www.tracklist.run/about)

**해석:** 새 곡을 만드는 대신 이미 좋아하던 음악과 이동을 연결하는 대안이다. ‘그날 들은 노래’가 오히려 더 기억에 남을 가능성도 있다.

**추천:** 신곡 생성이 기존 곡의 기억보다 가치 있다고 전제하지 않는다. 첫 청취 때 개인적인 의미가 생기는지 확인한다. 외부 음악 API 제한에 대한 사이트 설명은 별도 공식 API 문서를 확인하지 않았으므로 확정 사실로 전재하지 않는다.

### 3.2 비교에서 보여야 할 차이

좋은 설명은 “벤츠보다 더 똑똑한 AI”가 아니라 다음처럼 구체적이어야 한다.

> “오늘의 트랙은 다녀온 전체 여정의 기록으로 AI가 한 곡을 만든다. 어떤 기록을 곡의 구성에 사용했는지 돌아보고, 그날의 제목과 함께 다시 듣는다.”

이 문장은 제공하려는 경험이다. 실제 결과가 이 약속에 미치지 못하면 문구보다 구현 범위를 수정해야 한다. 벤츠나 Geosonify에 해당 기능이 절대로 없다는 비교 문장은 쓰지 않는다.

### 3.3 차량 앱이어야 하는 이유의 남은 숙제

**사실:** 스마트폰에서도 이동 기록과 반응형 음악은 가능하다. 차량 SDK에는 위치 외의 도메인이 있지만 그 존재만으로 가치가 증명되지 않는다. [AudioDrive](https://apps.apple.com/us/app/audiodrive-drive-make-music/id6636472047), [Pleos Vehicle](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro)

**해석:** 차량 앱의 우위 후보는 출발·기록·도착 후 감상의 이어짐, 실제 지원 차량 기록의 음악 기여, 차량 미디어와의 통합이다. 별도 휴대폰을 꺼내지 않는 편의만으로 독창성이 충분한지는 미확인이다.

**추천:** Odometer 숫자를 장식으로 보여주는 데 그치지 말고, 유효한 관측값이 여정 해석·곡 구성 요청에 어떻게 기여했는지와 실제 음원이 이를 따랐는지를 나눠 보여준다. AI 생성의 변동성도 고려해 비교한다. 차량 정보가 없으면 위치 기반 결과로 구분한다.

### 조사로 말할 수 없는 것

이번 조사로 시장의 빈 공간, 고객 지불 의향, 경쟁사 음질 우열, 한국에서의 전 기능 제공, 특허 신규성, 서비스 안정성을 입증하지 않았다. 각 기업의 투자금·다운로드·MAU도 비교 가능한 공식 자료를 확보하지 않아 표에 넣지 않았다. 공개된 앱스토어 평가 수를 활성 사용자로 환산하지 않는다.

기아·벤츠 발표는 실제 선행 사례지만 범용 앱 API의 제공을 의미하지 않는다. 포르쉐·Endel의 오래된 연구를 현재 출시 제품으로 세지 않았다. Geosonify 같은 작은 도구도 기능 중복을 보여주는 근거가 되며, 사용자 수가 작다고 추정해 배제하지 않았다.

## 5. 추천과 다음 조사

### 5.1 지금의 추천

**실제 주행이 끝난 뒤 전체 기록으로 AI가 한 곡을 만드는 경험에 집중한다.** 기록을 해석하고 곡의 구성을 요청하는 부분은 앱이 설계하되, 실제 곡은 AI가 생성한다. 규칙 기반 악보·AI 편곡 보조로 한정했던 기존 추천은 현재 기획에서 사용하지 않는다. 월간·여행 앨범과 폰 기능은 핵심 경험을 소장·재사용하게 하는 역할이다.

아직 확인하지 못한 위험 중 우선순위는 실제 음원의 감상 품질, 여정 반영의 의미, 차량 데이터의 기여다. 기능을 많이 추가하는 것보다 다음 증거가 방향 결정을 더 돕는다.

### 5.2 시장·가격을 다루는 방법

글로벌 음악 생성 시장의 총액을 가져와 이 앱의 시장으로 삼지 않는다. 실제 배포·지원 가능한 차량 기반과 여행 이용 행동이 먼저다. 오늘의 트랙의 예상 MAU·Retention·가격은 자료 부족으로 산정하지 않았다.

가설 검증에는 무료 첫 경험, 추가 스타일·편곡·내보내기 단위의 유료 옵션을 고려할 수 있다. Relive 같은 구독 사례나 AudioDrive의 구매 항목은 가능한 과금 형태의 참고일 뿐, 이 앱의 지불 의향 증거가 아니다. 가격·사용권은 날짜·지역·플랜에 따라 달라지므로 실제 도입 전에 다시 확인한다.
