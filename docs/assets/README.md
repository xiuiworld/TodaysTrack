원본은 개발 PC의 Git 제외 기기 증거 폴더에 보존합니다. 앱과 에뮬레이터를 다시 실행하지 않고 선정한 캡처만 공개했습니다.

날짜·시각·8km 거리·음악은 SDK 합성 주행 검증 데이터입니다. 개인의 실제 경로나 실도로 주행 결과가 아닙니다. 1:33과 1:41 곡은 기존 검증에서 실제 생성·저장한 음악이며, 대역 곡은 앱 안에서 별도로 표시합니다. 시각은 캡처 당시 기기 설정을 그대로 유지했습니다. 커버는 고정 장식 이미지입니다.
