검토 사례

우선 검토할 판단

① 시각 역행·거리 공백이 연속거리로 합산되는가? ② 정확히 같은 좌표만 동일 위치로 보는 현재 규칙은 적절한가? ③ 순서·비중·반복 관측이 실제 음악 요청에 충분히 반영되는가?

사용자 판단 전에는 귀환 반경·머묾 기준·음악적 해석을 바꾸지 않습니다. 실제 생성곡의 반영·청취 품질은 이 화면으로 검증할 수 없습니다.

원본 입력 / 같은 입력으로 다시 실행

아래는 저장 이벤트 경계의 입력입니다. 편집 후 실행하면 두 Kotlin 버전이 같은 입력을 사용합니다. SDK 콜백·Room 쓰기·공백 자동 생성은 실행하지 않습니다.

관측 채택·제외 근거

원본 quality와 신규 요약 투영 결과를 대조합니다. 정책 진단은 실제 수집 서비스 실행과 구별합니다.
